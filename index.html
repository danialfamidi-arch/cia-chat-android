Pasang CIA CHAT di HP

Agar CIA CHAT punya ikon sendiri dan terbuka seperti aplikasi, pasang melalui Chrome Android.

  1. Buka situs CIA CHAT menggunakan Google Chrome.
  2. Tekan menu ⋮ di pojok kanan atas Chrome.
  3. Pilih Install app atau Tambahkan ke layar utama.
  4. Tekan Install / Tambahkan, lalu buka ikon CIA CHAT dari layar HP.
Jika tombol Install app belum muncul, pastikan situs memakai HTTPS dan muat ulang halaman setelah deployment selesai.
